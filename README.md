## Baseline (Intercept-Only Normal) Model

**The model:**

$$y \sim \text{Normal}(\mu, \sigma)$$ $$\mu = \alpha$$

- **y** = nest initiation date (Julian day of year)
- **μ** = mean nest initiation date
- **α** = intercept
- **σ** = standard deviation
